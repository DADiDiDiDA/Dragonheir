# Dragonheir · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。

## 它能做什么

自动完成每日活跃度相关的主要操作。具体任务与触发条件见 `assets/interface.json`。

## 使用前的游戏设置

- 模拟器分辨率建议 **1920 × 1080**
- 关闭游戏设置里的「省电模式」
- ⚠️ 游戏偶尔会自动退出登录，而重新登录需要 QQ / 微信扫码，任务会在此卡住（暂无法自动处理）
- ⚠️ 部分机型会出现材质缺失（图标变黑块），严重影响图像识别，目前无法规避
