# Dragonheir · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。

## 它能做什么

基于 `assets/interface.json` 配置，自动完成以下日常任务：

- **🎮 启动游戏**：启动游戏并进入主界面
- **📧 领取邮箱奖励**：一键领取邮箱中的所有奖励
- **⚔️ 第一次刷体力**：自动扫荡指定副本；需要手动选择要刷取的副本类型和战斗方式；确保你打得过最新的关卡！！！打不过用扫荡卷，不然会卡住
- **🏛️ 工会签到**：进入工会并进行金币捐赠签到
- **🏝️ 收取海岛矿场资源**：领取海岛矿场资源
- **🐾 收取海岛宠物资源**：领取海岛宠物孵化资源并开始新的孵化
- **📤 收取海岛派遣资源**：领取海岛派遣任务奖励
- **🎲 召唤界面购买骰子**：在召唤界面购买一个骰子，以完成每日任务（每次执行都会买一次欧）
- **🌀 刷取时空涡流**：自动挑战时空涡流并领取奖励（不打狂暴时空涡流欧）
- **⚔️ 使用剩余体力**：自动扫荡指定副本；需要手动选择要刷取的副本类型和战斗方式；确保你打得过最新的关卡！！！打不过用扫荡卷，不然会卡住
- **📋 领取任务奖励**：领取每日任务奖励
- **🎫 领取游踪奖励**：领取游踪奖励

> 在 MaaFramework 启动器的任务列表中勾选 / 取消对应项，即可自定义要运行的任务。

## 使用前的游戏设置

- 模拟器分辨率建议 **1920 × 1080**
- 关闭游戏设置里的「省电模式」
- ⚠️ 游戏偶尔会自动退出登录，而重新登录需要 QQ / 微信扫码，任务会在此卡住（暂无法自动处理）
- ⚠️ 部分机型会出现材质缺失（图标变黑块），严重影响图像识别，目前无法规避
